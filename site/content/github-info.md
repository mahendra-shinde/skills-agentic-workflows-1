## Recent updates worth watching

- **Secret scanning now covers Actions logs (public preview):** GitHub secret scanning detects secrets in GitHub Actions workflow logs, in addition to issues, wikis, discussions, and pull requests. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs).
- **A more informative GitHub dashboard:** The dashboard now uses space more efficiently so you can see what needs attention with less navigation. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-10-a-more-informative-github-dashboard).
