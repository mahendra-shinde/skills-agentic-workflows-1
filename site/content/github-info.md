## Recent updates worth watching

- **New pull request overview page (public preview):** a quicker way to see what's blocking a long pull request without scrolling through comments and timeline events. [Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview)
- **`pull_request_target` blocked by default from December 2, 2026:** GitHub Actions will block these events in public repositories unless an Actions event policy allows them, so review your workflows now. [Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **GitHub Copilot in more IDEs:** now available in [JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air) and [Xcode's coding assistant](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant).
