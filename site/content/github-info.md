## Recent updates worth watching

- **`pull_request_target` blocked by default:** Starting December 2, 2026, GitHub Actions blocks `pull_request_target` events in public repositories unless an Actions event policy allows them. Check which runs would be affected before enforcement. [Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **Issue types and fields for personal accounts:** Issue types and issue fields are now generally available on personal-account repositories, so solo developers and maintainers can standardize issue planning. [Changelog](https://github.blog/changelog/2026-11-11-issue-types-and-fields-are-available-for-personal-accounts)
- **Secret scanning for Actions logs (public preview):** Secrets leaked in workflow logs can now be detected for Enterprise Cloud with Secret Protection or Advanced Security. [Changelog](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs)
