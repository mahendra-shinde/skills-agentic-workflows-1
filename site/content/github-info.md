## Recent updates worth watching

- **Async merge API is generally available:** merge single or stacked pull requests, or add them to a merge queue, by submitting a `PUT` and polling with `GET`. It is now the recommended way to merge programmatically. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-github-async-merge-api-generally-available).
- **Dynamic workflows in Copilot CLI and the Copilot app:** define an orchestration in code for more reliable multi-step Copilot tasks. Source: [GitHub Changelog](https://github.blog/changelog/2026-10-01-dynamic-workflows-in-copilot-cli-and-the-copilot-app).
