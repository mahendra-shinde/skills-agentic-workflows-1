## Recent updates worth watching

- **Pull request overview page (public preview):** a new overview page surfaces what's blocking a long pull request without scrolling through comments and timeline events. [Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview)
- **`pull_request_target` blocked by default:** starting December 2, 2026, GitHub Actions blocks `pull_request_target` events in public repositories unless an Actions event policy allows them. Review your workflows now. [Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **Copilot in more editors:** GitHub Copilot is now available in [JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air) and [Xcode's coding assistant](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant).
