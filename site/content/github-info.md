## Recent updates worth watching

- **Actions security:** Starting December 2, 2026, GitHub Actions blocks `pull_request_target` events by default in public repositories unless an applicable Actions policy allows them. Review your workflows now. ([GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2/))
- **Secret scanning:** Secret scanning now also detects secrets in GitHub Actions workflow logs, alongside issues, wikis, discussions, and pull requests. ([GitHub Changelog](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs/))
- **Pull requests:** A new pull request overview page (public preview) helps you see what is blocking a long pull request without scrolling through comments and timeline events. ([GitHub Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview/))
