- docs.github.com

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent changelog highlights

- [New pull request overview page in public preview](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview): a new view for browsing pull requests; worth a look when reviewing collaboration workflows.
- [`pull_request_target` blocked by default from December 2](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2): check Actions workflows that use this trigger before the change lands.
- [GitHub Copilot is now available in Xcode's coding assistant](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant) and [in JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air): more IDE options for Copilot.
