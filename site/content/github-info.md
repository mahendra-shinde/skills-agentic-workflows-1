## Recent updates worth watching

- **Wait for pull request events from the terminal:** GitHub CLI v2.105.0 adds `gh event listen`, which waits for a pull request event (such as a submitted review, check suite completion, or merge conflict) with one command instead of a polling loop. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli).
- **Clearer pull request overview:** The public-preview pull request Overview page now shows clearer merge status and next steps, and failed optional checks no longer make mergeable pull requests look blocked. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview).
- **Agent skills guide:** A practical walkthrough of building agent skills that run on any agent. Source: [GitHub Blog](https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/).
