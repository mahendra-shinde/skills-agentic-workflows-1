## Recent updates worth watching

- **Actions security:** Starting December 2, 2026, GitHub Actions blocks `pull_request_target` events by default in public repositories unless an Actions event policy allows them. Check your workflows before then. [Source](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **Copilot in your team chat:** `@GitHub` in Slack and Teams is now generally available, so you can investigate bugs, create issues, and open pull requests from a conversation. [Source](https://github.blog/changelog/2026-11-06-github-copilot-in-slack-and-teams-is-generally-available)
- **Pull request overview:** A new pull request overview page is in public preview. [Source](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview)
