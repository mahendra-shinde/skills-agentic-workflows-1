- **Pull requests:** a new pull request overview page is in public preview. ([Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview))
- **Copilot:** @GitHub in Slack and Teams is generally available. ([Changelog](https://github.blog/changelog/2026-11-06-github-copilot-in-slack-and-teams-is-generally-available))
