## Recent updates worth watching

- **Actions security:** Starting December 2, 2026, GitHub Actions blocks `pull_request_target` events by default in public repositories unless an Actions event policy allows them. Check your workflows now. ([Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2))
- **Pull requests:** A new opt-in Overview page (public preview) puts merge status and next actions in a compact summary at the top of a pull request. ([Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview))
- **Secret scanning:** Secret scanning can now detect secrets in GitHub Actions workflow logs (public preview, for Enterprise Cloud with Secret Protection or Advanced Security). ([Changelog](https://github.blog/changelog/2026-11-09-secret-scanning-detects-secrets-in-github-actions-workflow-logs))
