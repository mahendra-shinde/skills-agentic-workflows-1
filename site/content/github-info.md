## Recent updates worth watching

- **Pull request overview (public preview):** An opt-in Overview page puts merge status and next actions at the top of long pull requests, so you can see what is blocking a merge without scrolling. [Source](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview)
- **`pull_request_target` blocked by default on December 2, 2026:** GitHub Actions will block this trigger in public repositories unless an Actions event policy allows it. Review workflows that rely on it before then. [Source](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)
- **Copilot in Xcode and JetBrains Air:** GitHub Copilot is now available in Xcode's coding assistant and in JetBrains Air. Sources: [Xcode](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant), [JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air)
