## Recent updates worth watching

- **Pull request overview page (public preview):** an opt-in page that puts merge status and next actions at the top of a pull request, so you can see what's blocking a merge without scrolling. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview).
- **`pull_request_target` blocked by default on December 2, 2026:** GitHub Actions will block certain `pull_request_target` runs in public repositories by default. Use Insights to check which of your workflow runs the rule would block. Private and internal repositories aren't affected. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2).
- **Issue statuses and repository boards (public preview):** new planning features for issues. Source: [GitHub Changelog](https://github.blog/changelog/2026-11-23-issue-statuses-and-repository-boards-are-in-public-preview).
