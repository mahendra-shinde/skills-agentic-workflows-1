## Recent updates worth watching

- **Actions security change:** Starting December 2, 2026, GitHub Actions blocks `pull_request_target` events by default in public repositories unless an Actions event policy allows them. Review workflows that rely on it. ([Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2))
- **Copilot in more tools:** GitHub Copilot is now available in JetBrains Air, so you can delegate coding tasks and review results using the Agent Client Protocol. ([Changelog](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air))
